# 🛍️ Mall Customer Segmentation using K-Means Clustering

## 📌 Project Overview

This project applies the **K-Means Clustering** algorithm to segment customers of a retail mall based on their purchasing behavior. By analyzing customer income and spending patterns, the model identifies distinct customer groups that can help businesses improve marketing strategies and customer engagement.

## 🎯 Objective

The goal of this project is to group customers into meaningful segments using unsupervised machine learning techniques. These segments can be used for targeted promotions, personalized marketing, and business decision-making.

---

## 📂 Dataset

**Dataset:** Mall Customer Dataset

### Features

* CustomerID
* Gender
* Age
* Annual Income (k$)
* Spending Score (1-100)

## 📊 Methodology

1. Load and explore the dataset.
2. Select relevant features:

   * Annual Income (k$)
   * Spending Score (1-100)
3. Use the **Elbow Method** to determine the optimal number of clusters.
4. Train the K-Means Clustering model.
5. Visualize customer segments and cluster centroids.
6. Interpret customer behavior patterns.

---

## 📈 Results

The K-Means algorithm successfully segmented customers into distinct groups based on their spending habits and annual income levels. These clusters provide valuable insights for customer targeting and business strategy development.

Examples of identified customer groups include:

* High Income, High Spending
* High Income, Low Spending
* Low Income, High Spending
* Low Income, Low Spending
* Average Income, Average Spending
